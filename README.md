LIFE EXPECTANCY MACHINE LEARNING MODEL - 

A machine learning model that accepts data about country for a year and returns predicted average life expectancy after being trained on dataset from user-uploaded CSV, using data visualization and analysis techniques to help in feature selection and feature engineering. 

Numpy, SciPy, Matplotlib, Pandas

FEATURES - 
CSV Upload --> Upload and cleaning of dataset on life expectancy to eliminate redundant features and encode categorical features into numerical ones
Visualization --> Use of scatter plots, bar plots and graphs to show relation between pairs of features and their averages grouped by region
Model Development --> Training of model on dataset using LinearRegression for fitting in order to make predictions on test data about average life expectancy
Model Testing --> Testing of model on data after training and fitting in order to predict average life expectancy with one model variation using dummy variables
Model Evaluation --> Evaluation of model using different brackets of life expectancy and ConfusionMatrix to maximize accuracy of model trained on optimized features
